# ‏מעבר ל-Cloudflare

## ‏למה בכלל

‏יש כותרות אבטחה שאי אפשר לשלוח מתוך HTML · הן חייבות להגיע
‏מהשרת. `frame-ancestors`, שמונע ממישהו להטמיע את האתר בתוך
‏iframe ולרמות אנשים ללחוץ, היא העיקרית. **GitHub Pages אינו
‏מאפשר לשנות כותרות בכלל**, ולכן זה הדבר היחיד ברשימת האבטחה
‏שהפלטפורמה חוסמת.

## ‏איך · ולמה לא בדרך שנראית פשוטה יותר

‏הדרך שנשמעת קלה היא להשאיר את GitHub Pages ולשים את Cloudflare
‏כפרוקסי מעליו (הענן הכתום). **זה לא עובד טוב.** כש-Cloudflare
‏מתווך, GitHub אינו רואה את התעבורה שנדרשת לו כדי להנפיק ולחדש
‏את תעודת ה-HTTPS שלו, והתוצאה היא תעודה שלא מתחדשת ולולאות
‏הפניה. זאת תקלה מוכרת, ולא משהו שמסתדר עם הגדרה אחת.

‏הדרך הנכונה היא **Cloudflare Pages**: Cloudflare עצמו מגיש את
‏האתר ומנהל את התעודה, אין שתי שכבות שנאבקות זו בזו, והכותרות
‏יושבות בקובץ `_headers` בריפו · כלומר בגיט, עם היסטוריה, ולא
‏בלחיצות בלוח בקרה שאיש לא יזכור בעוד חצי שנה.

‏Cloudflare ממליצה היום על Workers לפרויקטים חדשים, אבל Pages
‏נתמך במלואו והוא בדיוק המקרה הזה: אתר סטטי שמתפרסם מגיט.

## ‏הצעדים

1. **Cloudflare → Add a site** · `shohamfinance.co.il`, התוכנית
   החינמית מספיקה.
2. ‏Cloudflare ייתן **שני שרתי שמות**. להחליף אותם אצל רשם
   הדומיין (זה שבו קנית את הכתובת). זה הצעד היחיד שלוקח זמן ·
   בין דקות לכמה שעות.
3. **Workers & Pages → Create → Pages → Connect to Git** ·
   לבחור את `Minapchimtkis/Shoham-Landing`, ענף `main`.
4. ‏בהגדרות הבנייה: **אין פקודת בנייה**, ותיקיית הפלט היא
   `/` · האתר הזה סטטי ואין בו שלב בנייה.
5. ‏אחרי הפרסום הראשון: **Custom domains** בפרויקט, להוסיף גם
   את `shohamfinance.co.il` וגם את `www`.
6. **לכבות את GitHub Pages** (Settings → Pages → Source: None),
   אחרת שתי גרסאות חיות של אותו אתר.

## ‏מה משתנה בעבודה היומית

‏כלום. דחיפה ל-`main` מפרסמת, בדיוק כמו היום.

## ‏מה לבדוק אחרי

‏מהטלפון או מהמחשב, אחרי שהאתר עלה:

- ‏הדף נפתח ב-`https://shohamfinance.co.il` וגם ב-`www`.
- ‏הטופס שולח ליד, והליד מופיע בדשבורד.
- ‏האפליקציה ב-`/app/` נפתחת ואפשר להיכנס.
- ‏בכלי הפיתוח, לשונית Network, בשורה של הדף עצמו · צריכות
  להופיע הכותרות מ-`_headers`.

## ‏דברים לדעת

- **HSTS אינו הפיך מיידית.** דפדפן שקיבל את הכותרת יסרב לגשת
  לאתר ב-HTTP עד שהיא תפוג, שנה. כל הדומיין כבר ב-HTTPS ולכן
  זה בטוח, אבל זה לא מתג שמכבים.
- ‏הקובץ `CNAME` בריפו שייך ל-GitHub Pages בלבד. הוא לא מזיק,
  ואפשר למחוק אותו אחרי המעבר.
- ‏ה-CSP נשאר בתגית `meta` בכל עמוד. הוא לא עובר לכותרות, כדי
  שיישאר מקור אמת אחד שחי בקוד של הדף ולא בשני מקומות.
